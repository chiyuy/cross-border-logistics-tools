二、装箱数量估算：三种口径
口径 1：体积法（只用于粗略报价）
```
箱数 ≈ 柜内容积 × 0.8 ÷ 单箱体积
```
误差来源：纸箱尺寸无法整除柜体空间时，会浪费 10%-30%。
口径 2：截面法（手工可用）
算纸箱在柜宽方向能放几个（用外尺寸 + 0.5cm 间隙）
算高度能叠几层（注意门高比柜内矮 10cm）
算柜长能排几排
```
箱数 = 宽向个数 × 层数 × 长向排数
```
口径 3：几何排布模拟（最准）
输入每箱的长宽高、重量、数量、是否可倒/可旋转，逐箱计算落位。

托盘混装的关键：托盘区长度按托盘长边推进，剩余长度给纸箱；托盘上方高度用矮箱补足，否则每柜浪费 3-5 CBM。

四、CBM 换算
```
1 CBM = 1 立方米 = 35.315 立方英尺
1 立方英尺 = 0.0283 CBM
```
海运拼箱（LCL）计费：
```
计费立方 = max(实际体积, 重量 ÷ 1000)
```
> 即：1 CBM 允许 1000 kg，超过按重量折算体积（重货）。空运则是 ÷6000。

五、成本分摊到单件
```
单件到岸成本 = 采购价 + 头程分摊 + 关税 + 平台佣金 + 仓储配送 + 广告 + 退货损耗
头程分摊（整柜）= 柜费 ÷ 总箱数
头程分摊（拼箱）= CBM 单价 × 单箱体积
```

六、常见问题
Q：20 尺柜装 50×40×30cm 纸箱能装多少？
A：理论 270 箱，常规装法 240-260 箱，留叉车通道时 200-220 箱。
Q：40HQ 比 40GP 划算吗？
A：泡货（体积重 > 实重）明显划算，多 10 CBM；重货则没必要，载重反而相同。
Q：托盘必须打托吗？
A：看客户与平台要求。打托便于机械化装卸、减少货损，但会损失 15%-20% 空间。
Q：装柜计算器算得准吗？
A：几何排布是确定的，误差来自纸箱受压形变与人工摆放，建议按结果打 95 折。
