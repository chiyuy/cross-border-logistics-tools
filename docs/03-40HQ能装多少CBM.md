# 40HQ 能装多少 CBM？实装率与算法

## 一、标准答案

| 口径 | 数值 |
|---|---|
| 理论容积 | **76.3 CBM** |
| 实装建议 | **68 CBM**（约 89%） |
| 极限实装 | 70-72 CBM（货品整齐、可叠到顶） |
| 泡货可能更低 | 60-65 CBM（不可压、需留通道） |

## 二、为什么装不到 76 CBM

三层损耗：

| 损耗来源 | 影响 |
|---|---|
| 排布缝隙 | 5%-8%（尺寸无法整除柜体） |
| 门框限制 | 最后一排不能码满，约 2%-3% |
| 人工摆放 | 2%-5%（取决于装柜工人经验） |

```
76.3 × (1 - 0.11) ≈ 68 CBM
```

## 三、不同货型的实装参考

| 货型 | 40HQ 实装 | 装载率 |
|---|---|---|
| 标准纸箱 50×40×30 | 1150-1250 箱 | 88%-92% |
| 小件 30×20×15 | 2600-2900 箱 | 85%-90% |
| 托盘 120×80×80 | 20-22 托 | 70%-80% |
| 大件家具（不可叠） | 45-55 CBM | 60%-70% |
| 卷材/布匹 | 60-68 CBM | 78%-88% |

## 四、CBM 与运费的关系

### 整柜（FCL）

按柜计费，与装多少无关。所以：

```
装载率 89% → 单件运费低
装载率 65% → 单件运费高 27%
```

**这就是为什么「差 5 CBM 少一个柜」值得花时间算。**

### 拼箱（LCL）

按 CBM 计费，但有一个隐藏规则：

```
计费立方 = max(实际体积, 重量 ÷ 1000)
```

即 1 CBM 只允许 1000kg。若 1 CBM 货重 1500kg，按 1.5 CBM 计费。

## 五、40HQ vs 40GP 的成本对比（算例）

货：1200 箱，共 68 CBM，12 t。

| 方案 | 柜型 | 装载率 | 说明 |
|---|---|---|---|
| A | 40GP × 1 | 100.4%（装不下） | ❌ 差 0.3 CBM |
| B | 40GP + 拼箱 | — | 麻烦、成本高 |
| C | 40HQ × 1 | 89% | ✅ 一柜搞定 |

**结论**：68 CBM 是 40GP 与 40HQ 的分水岭。超过 67 CBM 就必须用 HQ，否则要拆柜。

## 六、40HQ 的实际使用建议

| 场景 | 建议 |
|---|---|
| 泡货（体积重 > 实重） | 优先 HQ，顶部空间要用满 |
| 重货（实重 > 体积重） | 算重量，26.5 t 是大头 |
| 混装 | 重货在下、轻货在上，重心压在柜体中部 |
| 托盘货 | 托盘上方 79cm 要补矮箱，否则浪费 3-5 CBM |

## 七、快速估算公式

```
可装 CBM ≈ 柜型容积 × 0.88
可装箱数 ≈ 可装 CBM ÷ 单箱 CBM
```

40HQ 算例（单箱 0.06 CBM）：

```
76.3 × 0.88 = 67.1 CBM
67.1 ÷ 0.06 ≈ 1118 箱
```

再按纸箱排布打 95 折：约 1060 箱。
