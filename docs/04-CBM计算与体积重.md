# CBM 怎么算？体积、体积重与计费立方

## 一、CBM 是什么

CBM = Cubic Meter，立方米。国际物流中最基础的计量单位。

```
1 CBM = 1 m³ = 35.315 ft³
1 ft³ = 0.02832 CBM
```

## 二、单箱 CBM 计算

```
CBM = 长(cm) × 宽(cm) × 高(cm) ÷ 1,000,000
```

示例：60 × 40 × 40 cm

```
60 × 40 × 40 = 96,000 cm³
96,000 ÷ 1,000,000 = 0.096 CBM
```

整批：

```
总 CBM = 单箱 CBM × 箱数
0.096 × 200 = 19.2 CBM
```

## 三、三种「重」的区别

| 名称 | 算法 | 用途 |
|---|---|---|
| 实重 | 称重，kg | 载重限制 |
| 体积重（海运） | CBM × 1000 | 拼箱计费 |
| 体积重（空运） | 长×宽×高(cm) ÷ 6000 | 空运计费 |
| 计费重 | max(实重, 体积重) | 最终收费依据 |

### 空运示例

单箱 60×40×40cm，实重 15kg：

```
体积重 = 96,000 ÷ 6,000 = 16 kg
计费重 = max(15, 16) = 16 kg
```

泡货按体积重收费，实货按实重收费。

## 四、海运拼箱的计费立方

```
计费立方 = max(实际 CBM, 实重 ÷ 1000)
```

示例：

| 货物 | 体积 | 实重 | 计费 |
|---|---|---|---|
| 泡货（抱枕） | 3 CBM | 400 kg | 3 CBM |
| 实货（五金） | 1 CBM | 1,500 kg | **1.5 CBM** |

**重货会被按重量折算体积**，这是拼箱报价最容易算错的地方。

## 五、CBM 与柜型匹配

| 总 CBM | 建议柜型 |
|---|---|
| ≤ 28 | 20GP |
| 28-58 | 40GP |
| 58-68 | 40HQ |
| 68-78 | 45HQ |
| 78-110 | 2 × 40HQ |
| > 110 | 多柜或整批拆运 |

> 以上是「实装」口径，不是理论容积。

## 六、常见错误

| 错误 | 后果 |
|---|---|
| 用内径算 CBM | 少算 3%-5% |
| 忘了托盘体积 | 托盘 120×80×15cm 就有 0.144 CBM/个 |
| 混装时不加总 | 分批到货容易漏算 |
| 按理论容积订柜 | 普遍差 10%-12%，可能装不下 |

## 七、托盘 CBM 速查

| 托盘尺寸 | 单层高 15cm | 含货高 100cm |
|---|---|---|
| 120 × 80 | 0.144 CBM | 0.96 CBM |
| 120 × 100 | 0.18 CBM | 1.2 CBM |
| 110 × 110 | 0.18 CBM | 1.21 CBM |

托盘货按「托盘数 × 含货体积」计算，别只算货物本身。
